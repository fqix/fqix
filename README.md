### Hi, I'm fengqi 👋

I build developer tools that make remote environments feel local — **VS Code extensions** for networking, SSH and debugging, and **cloud-native** tooling that brings Kubernetes pods and services within reach of your laptop. Mostly in **Go** and **TypeScript**.

#### ☁️ Cloud native & Kubernetes

- **[kube-loop](https://github.com/fqix/kube-loop)** — cross-platform Kubernetes desktop network client: transparent TUN access to Pod IPs, ClusterIP Services and cluster DNS, built on sing-box.
- **[PodRelay](https://github.com/fqix/podrelay)** — SSH and VS Code Remote access to Kubernetes pods running a stock `sshd`, through a WebSocket relay with per-pod SSH key auth.

Also interested in multi-tenant clusters ([vCluster](https://github.com/loft-sh/vcluster)), ingress and API gateways ([Apache APISIX](https://github.com/apache/apisix-ingress-controller)), and AI training on Kubernetes ([Kubeflow Trainer](https://github.com/kubeflow/trainer)).
